# SuryaCheck frontend

React + TypeScript + Vite app (landing page, `/test` flow and results, history, settings).
See the [project README](../README.md) for what it does, architecture, and how to run and deploy it.

```bash
npm ci
npm run dev       # needs VITE_API_URL (see .env.example)
npm run build     # type-checks, then builds to dist/
```
